# Example profile

A fictional language school used by every example in this repository.
Nothing here describes a real business.

- `profile.yaml` — product, audience, market, languages, channels, brand, links, UTM defaults.
- `assets/` — logo and product screenshots (generated from `demo-site/`).
- `demo-site/` — a static page that stands in for the product; reels record it.
- `fonts/` — Inter (SIL Open Font License 1.1, see `Inter-OFL.txt`).

Make your own: copy this folder outside the repository, edit `profile.yaml`, replace the assets,
then pass `--profile /path/to/folder` (or set `GROWTH_PROFILE`).
