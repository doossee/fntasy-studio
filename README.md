# growth-studio

Open skills and tools for AI agents: growth research and content production (posts, carousels, stories, reels with sound) with first-class support for Telegram and the markets of Central Asia and the CIS.

Work in progress. The first version is being built in `task/*` branches; see `docs/tasks/`.
