# Демо: режим (а) «разбор примера» — Duolingo

Короткий прогон навыка `growth` на крупной публичной компании (NASDAQ: DUOL).
Только открытые источники, без оценок. Дата проверки всех ссылок: **2026-11-15**.

Пометки: **видели** — страница открыта, факт на ней есть; **предполагаем** — вывод из увиденного;
**не увидели** — источник не открылся инструментами агента, шаг нужно пройти человеку в браузере.

Вымышленный «наш продукт» для выводов — языковая школа из `profiles/example`.
