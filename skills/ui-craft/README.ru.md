# ui-craft

Навык Claude Code о виде экранов программ: измеримые правила (пол) и метод для сильных экранов (потолок). English: [README.md](README.md).

## Установка

Скопируйте эту папку в `.claude/skills/ui-craft/` проекта или в `~/.claude/skills/ui-craft/`. Другой путь — поставить плагин `design-skills`, в который навык входит. Навык загружается сам, когда вы проектируете, верстаете или проверяете экран.

Скрипту измерений нужны Node 20+ и Playwright. Если Playwright ещё не установлен:

```bash
cd scripts && npm install && npx playwright install chromium
```

## Как пользоваться

- Попросите Claude собрать, довести или проверить экран: он идёт по `SKILL.md`.
- Попросите «варианты» или «редизайн»: включится режим свободы с 2–3 разными решениями (`references/16-freedom.md`).
- Измерьте любую страницу сами:

```bash
node scripts/measure.mjs https://example.com --widths 1440,390
node scripts/measure.mjs examples/acme-today-good.html examples/acme-today-bad.html --profile examples/design-profile.md
node scripts/measure.mjs --help
```

На каждую ширину скрипт сохраняет:

- снимок окна и снимок всей страницы;
- снимок с красными рамками нарушений;
- размытый снимок-«прищур»;
- `metrics.json` с девятью счётчиками стоп-пунктов и показателями композиции.

Каждое число объяснено в `references/11-measure.md`.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `SKILL.md` | вход: режимы, роды экранов, порядок работы |
| `profile.md` | профиль проекта `design-profile.md`: ключи, разделы, работа без профиля |
| `references/00-numbers.md` | все числа на одной странице |
| `references/01…10` | пол: отступы, поля, близость, выравнивание, типографика, компьютер, телефон, длинные слова, значки, состояния |
| `references/12…17` | потолок: композиция, данные, цвет, детали, режим свободы, типы ячеек таблицы |
| `references/11-measure.md` | скрипт |
| `checklist.md` | аудит: 9 стоп-пунктов, вопросы A–H и K, балл |
| `rubric-best.md` | семь критериев 0–4, независимый оценщик |
| `references/sources.md` | источники и то, что не подтвердилось |
| `examples/` | чистый экран, тот же экран с нарушениями, пример профиля |
| `scripts/` | `measure.mjs`, `lib/` |

## Примеры

`examples/acme-today-good.html` проходит с 0 стоп-пунктов на всех четырёх ширинах. `examples/acme-today-bad.html` — тот же экран с намеренным нарушением на каждый стоп-пункт и каждую метку композиции; каждое подписано комментарием в CSS рядом. Запустите оба файла, чтобы увидеть рамки и числа.

Лучше всего работает в паре с `ux-clarity`, который отвечает за сценарий.
