# ux-clarity

Навык Claude Code о понятности интерфейса: поймёт ли новый пользователь экран с первого раза, с телефона, без объяснений. 69 счётных правил и аудит из 54 вопросов с баллом. English: [README.md](README.md).

## Установка

Скопируйте эту папку в `.claude/skills/ux-clarity/` проекта или в `~/.claude/skills/ux-clarity/`. Другой путь — поставить плагин `design-skills`, в который навык входит. Навык загружается сам, когда вы проектируете, меняете или проверяете экран.

Скрипту измерений нужны Node 20+ и Playwright. Если Playwright ещё не установлен:

```bash
cd scripts && npm install && npx playwright install chromium
```

## Как пользоваться

- Попросите Claude спроектировать или изменить экран, форму, список, навигацию: он идёт по `SKILL.md`.
- Спросите «понятен ли экран?» или «можно ли показывать клиенту?»: он снимет экран, пройдёт `checklist.md` и назовёт балл, стоп-пункты и нарушения по убыванию вреда.
- Измерьте любую страницу сами:

```bash
node scripts/measure.mjs https://example.com
node scripts/measure.mjs examples/acme-payment-good.html examples/acme-payment-bad.html --profile examples/design-profile.md
node scripts/measure.mjs --help
```

На каждую ширину (по умолчанию 390 и 1440) скрипт сохраняет первый экран, всю страницу, первый экран с находками красным и `metrics.json`. В нём:

- прокрутка страницы вбок;
- цели касания меньше 44 px;
- тесные цели меньше 24 px;
- текст мельче 12 px;
- главные кнопки;
- подписи, обрезанные или перенесённые на три строки.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `SKILL.md` | вход: порядок работы, скрипт, что нельзя делать |
| `profile.md` | профиль проекта `design-profile.md`: ключи, разделы, работа без профиля |
| `references/00-audience.md` | кто пользователь и как взять это из профиля |
| `references/01…09` | навигация, главное действие, формы, списки на телефоне, состояния, отклик и отмена, тексты, касание, первый запуск |
| `checklist.md` | 54 вопроса «да / нет», балл, порог, протокол |
| `references/sources.md` | источники и числа, которые не подтвердились |
| `examples/` | понятная форма, та же форма с нарушениями, пример профиля |
| `scripts/` | `measure.mjs`, `lib/` |

## Примеры

`examples/acme-payment-good.html` — форма оплаты, которая проходит счётные проверки. `examples/acme-payment-bad.html` — та же форма с намеренными нарушениями; каждое подписано комментарием в CSS рядом.

Лучше всего работает в паре с `ui-craft`, который отвечает за вид экрана.
